[CrabNebula](https://crabnebula.dev/)는 Tauri 프로젝트와의 파트너십의 일환으로 Tauri용 무료 [DevTools](https://crabnebula.dev/devtools/) 애플리케이션을 제공합니다. 이 애플리케이션을 사용하면 포함된 자산, Tauri 구성 파일, 로그 및 범위를 캡처하여 Tauri 앱을 계측하고 웹 프런트엔드를 제공하여 데이터를 실시간으로 원활하게 시각화할 수 있습니다.

CrabNebula DevTools를 사용하면 앱의 로그 이벤트(의존성 로그 포함)를 검사하고, 페이로드, 응답 및 내부 로그와 실행 범위를 포함하여 Tauri 이벤트 및 명령을 위한 특수 인터페이스를 통해 명령 호출 및 전반적인 Tauri API 사용 성능을 추적할 수 있습니다.

CrabNebula DevTools를 활성화하려면 devtools 크레이트를 설치하십시오.

```sh frame=none
cargo add tauri-plugin-devtools@2.0.0
```

그리고 main 함수에서 가능한 한 빨리 플러그인을 초기화하십시오.

```rust
fn main() {
    // 이것은 앱 실행 시 가능한 한 빨리 호출되어야 합니다.
    #[cfg(debug_assertions)] // 개발 빌드에서만 계측 활성화
    let devtools = tauri_plugin_devtools::init();

    let mut builder = tauri::Builder::default();

    #[cfg(debug_assertions)]
    {
        builder = builder.plugin(devtools);
    }

    builder
        .run(tauri::generate_context!())
        .expect("error while running tauri application");
}
```

그런 다음 평소와 같이 앱을 실행하십시오. 모든 것이 올바르게 설정되면 devtools가 다음 메시지를 인쇄합니다.

<Image src={devToolsPrint} alt="터미널의 DevTools 메시지" />

:::note
이 경우 디버그 애플리케이션에 대해서만 devtools 플러그인을 초기화하는데, 이것이 권장됩니다.
:::

자세한 내용은 [CrabNebula DevTools](https://docs.crabnebula.dev/devtools/get-started/) 문서를 참조하십시오.
