이 가이드는 [Tauri 앱의 핵심 프로세스](/concept/process-model/#the-core-process)를 디버깅하기 위해 VS Code를 설정하는 과정을 안내합니다.

## vscode-lldb 확장이 있는 모든 플랫폼

### 필수 조건

[`vscode-lldb`] 확장을 설치합니다.

[`vscode-lldb`]: https://marketplace.visualstudio.com/items?itemName=vadimcn.vscode-lldb

### launch.json 구성

`.vscode/launch.json` 파일을 만들고 아래 JSON 내용을 붙여넣으십시오.

```json title=".vscode/launch.json"
{
  // IntelliSense를 사용하여 가능한 속성에 대해 알아봅니다.
  // 기존 속성에 대한 설명을 보려면 마우스를 가져갑니다.
  // 자세한 내용은 https://go.microsoft.com/fwlink/?linkid=830387을 방문하십시오.
  "version": "0.2.0",
  "configurations": [
    {
      "type": "lldb",
      "request": "launch",
      "name": "Tauri Development Debug",
      "cargo": {
        "args": [
          "build",
          "--manifest-path=./src-tauri/Cargo.toml",
          "--no-default-features"
        ]
      },
      // `beforeDevCommand`를 사용하는 경우 작업을 `.vscode/tasks.json`에서 구성해야 합니다.
      "preLaunchTask": "ui:dev"
    },
    {
      "type": "lldb",
      "request": "launch",
      "name": "Tauri Production Debug",
      "cargo": {
        "args": ["build", "--release", "--manifest-path=./src-tauri/Cargo.toml"]
      },
      // `beforeBuildCommand`를 사용하는 경우 작업을 `.vscode/tasks.json`에서 구성해야 합니다.
      "preLaunchTask": "ui:build"
    }
  ]
}
```

이것은 `cargo`를 직접 사용하여 Rust 애플리케이션을 빌드하고 개발 및 프로덕션 모드 모두에서 로드합니다.

Tauri CLI를 사용하지 않으므로 전용 CLI 기능은 실행되지 않습니다. `beforeDevCommand` 및 `beforeBuildCommand` 스크립트는 미리 실행하거나 `preLaunchTask` 필드에서 작업으로 구성해야 합니다. 아래는 개발 서버를 생성하는 `beforeDevCommand`용 작업과 `beforeBuildCommand`용 작업 두 가지가 있는 `.vscode/tasks.json` 파일 예제입니다.

```json title=".vscode/tasks.json"
{
  // tasks.json 형식에 대한 문서는 https://go.microsoft.com/fwlink/?LinkId=733558을 참조하십시오.
  "version": "2.0.0",
  "tasks": [
    {
      "label": "ui:dev",
      "type": "shell",
      // `dev`는 백그라운드에서 계속 실행됩니다.
      // 이상적으로는 `problemMatcher`도 구성해야 합니다.
      // https://code.visualstudio.com/docs/editor/tasks#_can-a-background-task-be-used-as-a-prelaunchtask-in-launchjson을 참조하십시오.
      "isBackground": true,
      // 이것을 `beforeDevCommand`로 변경하십시오.
      "command": "yarn",
      "args": ["dev"]
    },
    {
      "label": "ui:build",
      "type": "shell",
      // 이것을 `beforeBuildCommand`로 변경하십시오.
      "command": "yarn",
      "args": ["build"]
    }
  ]
}
```

이제 `src-tauri/src/main.rs` 또는 다른 Rust 파일에 중단점을 설정하고 `F5`를 눌러 디버깅을 시작할 수 있습니다.

## Windows의 Visual Studio Windows 디버거 사용

Visual Studio Windows 디버거는 열거형과 같은 일부 Rust 기능에 대한 더 나은 지원을 제공하며 일반적으로 [`vscode-lldb`]보다 빠른 Windows 전용 디버거입니다.

### 필수 조건

[C/C++](https://marketplace.visualstudio.com/items?itemName=ms-vscode.cpptools) 확장을 설치하고 https://code.visualstudio.com/docs/cpp/config-msvc#_prerequisites를 따라 Visual Studio Windows 디버거를 설치합니다.

### launch.json 및 tasks.json 구성

```json title=".vscode/launch.json"
{
  // IntelliSense를 사용하여 가능한 속성에 대해 알아봅니다.
  // 기존 속성에 대한 설명을 보려면 마우스를 가져갑니다.
  // 자세한 내용은 https://go.microsoft.com/fwlink/?linkid=830387을 방문하십시오.
  "version": "0.2.0",
  "configurations": [
    {
      "name": "Launch App Debug",
      "type": "cppvsdbg",
      "request": "launch",
      // exe 이름을 실제 exe 이름으로 변경하십시오.
      // (릴리스 빌드를 디버그하려면 `target/debug`를 `release/debug`로 변경하십시오)
      "program": "${workspaceRoot}/src-tauri/target/debug/your-app-name-here.exe",
      "cwd": "${workspaceRoot}",
      "preLaunchTask": "ui:dev"
    }
  ]
}
```

Tauri CLI를 사용하지 않으므로 전용 CLI 기능은 실행되지 않습니다. `tasks.json`은 시작하기 전에 항상 컴파일하려는 경우 구성 그룹을 추가하고 `launch.json`의 `preLaunchTask`를 해당 그룹으로 지정해야 한다는 점을 제외하고 `lldb`와 동일합니다.

다음은 개발 서버(`beforeDevCommand`에 해당)와 컴파일(`cargo build`)을 그룹으로 실행하는 예입니다. 이를 사용하려면 `launch.json`의 `preLaunchTask` 구성을 `dev`(또는 그룹 이름으로 지정한 이름)로 변경하십시오.

```json title=".vscode/tasks.json"
{
  // tasks.json 형식에 대한 문서는 https://go.microsoft.com/fwlink/?LinkId=733558을 참조하십시오.
  "version": "2.0.0",
  "tasks": [
    {
      "label": "build:debug",
      "type": "cargo",
      "command": "build",
      "options": {
        "cwd": "${workspaceRoot}/src-tauri"
      }
    },
    {
      "label": "ui:dev",
      "type": "shell",
      // `dev`는 백그라운드에서 계속 실행됩니다.
      // 이상적으로는 `problemMatcher`도 구성해야 합니다.
      // https://code.visualstudio.com/docs/editor/tasks#_can-a-background-task-be-used-as-a-prelaunchtask-in-launchjson을 참조하십시오.
      "isBackground": true,
      // 이것을 `beforeDevCommand`로 변경하십시오.
      "command": "yarn",
      "args": ["dev"]
    },
    {
      "label": "dev",
      "dependsOn": ["build:debug", "ui:dev"],
      "group": {
        "kind": "build"
      }
    }
  ]
}
```
