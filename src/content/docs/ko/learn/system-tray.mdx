시스템 트레이는 일반적으로 메뉴 모음이나 작업 표시줄의 아이콘으로 표시되는 운영 체제의 UI 요소입니다.

## 생성

시스템 트레이를 생성하려면 먼저 아이콘을 사용해야 합니다. [`tauri.conf.json`] 파일의 `app.trayIcon` 옵션을 사용하여 기본 트레이 아이콘을 설정할 수 있습니다.

```json title="tauri.conf.json"
{
  "app": {
    "trayIcon": "icons/icon.png"
  }
}
```

트레이 아이콘이 구성되면 런타임에 트레이를 생성할 수 있습니다.

### Rust

Rust에서 트레이를 생성하려면 [`TrayIconBuilder`] 구조체를 사용하십시오.

```rust
use tauri::{
  menu::{Menu, MenuItem},
  tray::TrayIconBuilder,
};

tauri::Builder::default()
  .setup(|app| {
    let quit_i = MenuItem::with_id(app, "quit", "종료", true, None::<&str>)?;
    let menu = Menu::with_items(app, &[&quit_i])?;

    let tray = TrayIconBuilder::new()
      .menu(&menu)
      .menu_on_left_click(true)
      .build(app)?;

    Ok(())
  })
```

`TrayIconBuilder`는 트레이 아이콘, 메뉴, 이벤트 처리기 등을 구성하는 많은 메서드를 제공합니다. 자세한 내용은 [문서](https://docs.rs/tauri/latest/tauri/tray/struct.TrayIconBuilder.html)를 참조하십시오.

### JavaScript

JavaScript에서 트레이를 생성하려면 `@tauri-apps/api/tray` 모듈의 [`TrayIcon`] 클래스를 사용하십시오.

:::note
JavaScript에서 시스템 트레이를 생성하려면 `tray:allow-create` 권한이 필요합니다.
:::

```javascript
import { TrayIcon } from '@tauri-apps/api/tray';
import { Menu } from '@tauri-apps/api/menu';

const menu = await Menu.new({
  items: [
    {
      id: 'quit',
      text: '종료',
    },
  ],
});

const tray = await TrayIcon.new({
  menu,
  menuOnLeftClick: true,
});
```

## 이벤트

트레이 아이콘은 클릭되거나 메뉴 항목이 선택될 때 이벤트를 방출합니다.

### Rust

Rust에서는 `on_tray_icon_event` 및 `on_menu_event`를 사용하여 이러한 이벤트를 처리할 수 있습니다.

```rust
use tauri::{
  menu::{Menu, MenuItem},
  tray::{MouseButton, MouseButtonState, TrayIconBuilder, TrayIconEvent},
};

tauri::Builder::default()
  .setup(|app| {
    let quit_i = MenuItem::with_id(app, "quit", "종료", true, None::<&str>)?;
    let menu = Menu::with_items(app, &[&quit_i])?;

    let tray = TrayIconBuilder::new()
      .menu(&menu)
      .on_menu_event(|app, event| match event.id.as_ref() {
        "quit" => {
          println!("종료 메뉴 항목이 클릭되었습니다");
          app.exit(0);
        }
        _ => {
          println!("메뉴 항목 {:?}이(가) 클릭되었습니다", event.id);
        }
      })
      .on_tray_icon_event(|tray, event| match event {
        TrayIconEvent::Click {
          button: MouseButton::Left,
          button_state: MouseButtonState::Up,
          ..
        } => {
          println!("왼쪽 클릭이 눌렸다 떼어졌습니다");
          // 기본적으로 이 이벤트에서는 왼쪽 클릭 시 앱이 표시되고 다시 클릭하면 숨겨집니다.
          let app = tray.app_handle();
          if let Some(window) = app.get_webview_window("main") {
            let _ = window.show();
            let _ = window.set_focus();
          }
        }
        _ => {
          println!("처리되지 않은 이벤트 {event:?}");
        }
      })
      .build(app)?;

    Ok(())
  })
```

### JavaScript

JavaScript에서는 `TrayIcon` 생성자의 옵션에서 이벤트 처리기를 지정할 수 있습니다.

:::note
JavaScript에서 트레이 이벤트를 처리하려면 적절한 권한을 구성해야 합니다.
:::

```javascript
import { TrayIcon } from '@tauri-apps/api/tray';
import { Menu } from '@tauri-apps/api/menu';

const menu = await Menu.new({
  items: [
    {
      id: 'quit',
      text: '종료',
      action: () => {
        console.log('종료 메뉴 항목이 클릭되었습니다');
        // 애플리케이션 종료 로직
      },
    },
  ],
});

const tray = await TrayIcon.new({
  menu,
  action: (event) => {
    switch (event.type) {
      case 'Click':
        console.log(
          `마우스 ${event.button} 버튼이 눌렸습니다, 상태: ${event.buttonState}`
        );
        break;
      case 'DoubleClick':
        console.log(`마우스 ${event.button} 버튼이 더블 클릭되었습니다`);
        break;
      case 'Enter':
        console.log(`마우스가 트레이 아이콘에 들어왔습니다`);
        break;
      case 'Move':
        console.log(`마우스가 트레이 아이콘 위에서 움직입니다`);
        break;
      case 'Leave':
        console.log(`마우스가 트레이 아이콘을 떠났습니다`);
        break;
    }
  },
});
```
