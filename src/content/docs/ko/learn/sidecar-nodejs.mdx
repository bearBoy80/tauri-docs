Node.js 사이드카를 사용하면 Tauri 애플리케이션에서 Node.js 스크립트를 실행할 수 있습니다.
이것은 Node.js 생태계의 풍부한 패키지를 활용하고 싶거나 기존 Node.js 코드를 재사용하려는 경우에 유용합니다.

## 전제 조건

Node.js 사이드카를 사용하려면 먼저 [사이드카 (외부 바이너리)](/develop/sidecar/) 가이드에 따라 기본적인 사이드카 설정을 수행해야 합니다.

또한 Node.js 런타임을 사이드카로 번들링해야 합니다. 이를 위해서는 일반적으로 [`pkg`](https://github.com/vercel/pkg)와 같은 도구를 사용하여 Node.js 스크립트를 실행 가능한 바이너리로 패키징합니다.

## 설정

1.  Node.js 프로젝트를 만들고 필요한 종속성을 설치합니다.

    ```bash
    mkdir my-sidecar
    cd my-sidecar
    npm init -y
    npm install
    ```

2.  `index.js` 파일을 만들고 실행할 코드를 작성합니다.

    ```javascript title="my-sidecar/index.js"
    console.log('Hello from Node.js sidecar!');
    ```

3.  `pkg`를 사용하여 Node.js 스크립트를 바이너리로 컴파일합니다.

    ```bash
    npx pkg index.js -t node18-linux-x64,node18-macos-x64,node18-win-x64 --out-path ../src-tauri/binaries
    ```

    :::note
    플랫폼 대상은 개발 환경 및 대상 환경에 맞게 조정하십시오.
    :::

4.  `src-tauri/binaries` 디렉토리 내의 바이너리 이름을 Tauri의 사이드카 명명 규칙에 따라 변경합니다.
    예: `my-sidecar-x86_64-unknown-linux-gnu`

5.  `tauri.conf.json`에서 사이드카를 구성합니다.

    ```json title="tauri.conf.json"
    {
      "bundle": {
        "externalBin": [
          "binaries/my-sidecar"
        ]
      }
    }
    ```

## 사용법

Rust 또는 JavaScript에서 사이드카를 실행할 수 있습니다.

### JavaScript

```javascript
import { Command } from '@tauri-apps/plugin-shell';

const command = Command.sidecar('binaries/my-sidecar');
const output = await command.execute();
console.log(output.stdout);
```

### Rust

```rust
use tauri_plugin_shell::ShellExt;

let sidecar_command = app.shell().sidecar("my-sidecar").unwrap();
let (mut _rx, _child) = sidecar_command.spawn().expect("Failed to spawn sidecar");
```

## 통신

사이드카와 기본 애플리케이션 간의 통신에는 일반적으로 표준 입출력(stdin/stdout)을 사용합니다.
Node.js 스크립트에서 `console.log`를 사용하여 데이터를 출력하고 Tauri 앱 측에서 이를 읽을 수 있습니다.
반대로 Tauri 앱에서 사이드카의 stdin에 데이터를 쓸 수도 있습니다.
