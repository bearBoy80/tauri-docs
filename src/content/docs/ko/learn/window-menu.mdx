창 메뉴는 애플리케이션의 일반적인 기능에 대한 액세스를 제공하는 중요한 UI 요소입니다.
Tauri에서는 크로스 플랫폼 기본 메뉴를 쉽게 만들 수 있습니다.

## 메뉴 만들기

메뉴는 Rust 또는 JavaScript로 만들 수 있습니다.

### Rust

Rust에서 메뉴를 만들려면 `tauri::menu` 모듈을 사용하십시오.

```rust
use tauri::menu::{Menu, MenuItem, Submenu};

tauri::Builder::default()
  .setup(|app| {
    let save_menu_item = MenuItem::with_id(app, "save", "저장", true, Some("cmd+s"))?;
    let file_menu = Submenu::with_items(app, "파일", true, &[&save_menu_item])?;
    let menu = Menu::with_items(app, &[&file_menu])?;

    app.set_menu(menu)?;

    Ok(())
  })
```

### JavaScript

JavaScript에서 메뉴를 만들려면 `@tauri-apps/api/menu` 모듈을 사용하십시오.

```javascript
import { Menu, Submenu, MenuItem } from '@tauri-apps/api/menu';

const saveMenuItem = await MenuItem.new({
  id: 'save',
  text: '저장',
  accelerator: 'CmdOrCtrl+S',
});

const fileMenu = await Submenu.new({
  text: '파일',
  items: [saveMenuItem],
});

const menu = await Menu.new({
  items: [fileMenu],
});

await menu.setAsAppMenu();
```

## 이벤트 처리

메뉴 항목을 클릭했을 때의 이벤트를 처리하려면 Rust의 `on_menu_event` 콜백 또는 JavaScript의 `action` 속성을 사용하십시오.

### Rust

```rust
tauri::Builder::default()
  .on_menu_event(|app, event| {
    match event.id.as_ref() {
      "save" => {
        println!("저장 메뉴 항목이 클릭되었습니다");
        // 저장 로직 실행
      }
      _ => {}
    }
  })
```

### JavaScript

```javascript
const saveMenuItem = await MenuItem.new({
  id: 'save',
  text: '저장',
  action: () => {
    console.log('저장 메뉴 항목이 클릭되었습니다');
    // 저장 로직 실행
  },
});
```

## 미리 정의된 메뉴 항목

Tauri는 일반적인 작업(복사, 붙여넣기, 잘라내기 등)을 위한 미리 정의된 메뉴 항목을 제공합니다. 이를 사용하면 OS 표준 동작을 쉽게 구현할 수 있습니다.

- `PredefinedMenuItem::copy(app, text)`
- `PredefinedMenuItem::cut(app, text)`
- `PredefinedMenuItem::paste(app, text)`
- ...등

자세한 내용은 [문서](https://docs.rs/tauri/latest/tauri/menu/struct.PredefinedMenuItem.html)를 참조하십시오.
