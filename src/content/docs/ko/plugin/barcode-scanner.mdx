## 구성

iOS에서 바코드 스캐너 플러그인은 `NSCameraUsageDescription` 정보 속성 목록 값을 필요로 하며, 이는 앱이 카메라를 사용해야 하는 이유를 설명해야 합니다.

`src-tauri/Info.ios.plist` 파일에 다음 스니펫을 추가하십시오:

```xml title=src-tauri/Info.ios.plist
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
	<dict>
		<key>NSCameraUsageDescription</key>
		<string>QR 코드 읽기</string>
	</dict>
</plist>
```

## 사용법

바코드 스캐너 플러그인은 JavaScript에서 사용할 수 있습니다.

```javascript
import { scan, Format } from '@tauri-apps/plugin-barcode-scanner';
// `"withGlobalTauri": true`를 사용할 때, 다음을 사용할 수 있습니다:
// const { scan, Format } = window.__TAURI__.barcodeScanner;

// `windowed: true`는 실제로 웹뷰를 투명하게 설정합니다.
// 카메라를 위한 별도의 뷰를 여는 대신입니다.
// 사용자 인터페이스가 투명한 요소 아래에 있는 것을 보여줄 준비가 되었는지 확인하십시오.
scan({ windowed: true, formats: [Format.QRCode] });
```

## 권한

기본적으로 잠재적으로 위험한 모든 플러그인 명령과 범위는 차단되어 액세스할 수 없습니다. 이를 활성화하려면 `capabilities` 구성에서 권한을 수정해야 합니다.

플러그인 권한을 사용하는 방법에 대한 자세한 내용은 [기능 개요](/security/capabilities/) 및 [단계별 가이드](/learn/security/using-plugin-permissions/)를 참조하십시오.

```json title="src-tauri/capabilities/mobile.json"
{
  "$schema": "../gen/schemas/mobile-schema.json",
  "identifier": "mobile-capability",
  "windows": ["main"],
  "platforms": ["iOS", "android"],
  "permissions": ["barcode-scanner:allow-scan", "barcode-scanner:allow-cancel"]
}
```
