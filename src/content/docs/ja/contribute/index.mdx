私たちメンテナは、あなたが Tauri への貢献に興味を持ってくれたことを本当に嬉しく思います。私たちは、あらゆるスキルレベルの貢献者を歓迎し、PR での指導も喜んで行います。
疑問がある場合は、[Discord サーバー](https://discord.gg/SpmNs4S) でお問い合わせください。

### プロジェクトリポジトリ

貢献できる主な Tauri リポジトリは次のとおりです：

- [Tauri Core](https://github.com/tauri-apps/tauri/) リポジトリ：Tauri ランタイム、ビルドツール、マクロ、ユーティリティが含まれています。
- [Plugins workspace](https://github.com/tauri-apps/plugins-workspace) リポジトリ：すべての公式 Tauri プラグインが含まれています。
- [Tauri Docs](https://github.com/tauri-apps/tauri-docs) リポジトリ：このウェブサイトが含まれています。

これらの各 Tauri リポジトリには `.github/CONTRIBUTING.md` ファイルが含まれています。その中には、ローカル開発環境のセットアップ方法と Pull Request の送信方法に関する説明があります。
