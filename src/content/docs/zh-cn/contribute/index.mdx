我们（维护者）非常高兴你有兴趣为 Tauri 做出贡献。我们欢迎任何技能水平的贡献者，并乐意为 PR 提供指导。
如果有任何疑问，你可以在 [我们的 Discord 服务器](https://discord.gg/SpmNs4S) 上联系我们。

### 项目仓库

你可以贡献的主要 Tauri 仓库有：

- [Tauri 核心](https://github.com/tauri-apps/tauri/) 仓库：包含 Tauri 运行时、构建工具、宏和实用程序。
- [插件工作区](https://github.com/tauri-apps/plugins-workspace) 仓库：包含所有官方 Tauri 插件。
- [Tauri 文档](https://github.com/tauri-apps/tauri-docs) 仓库：包含本网站。

每个 Tauri 仓库都包含一个 `.github/CONTRIBUTING.md` 文件。在其中，你可以找到有关如何设置本地开发环境和提交 Pull Request 的说明。
