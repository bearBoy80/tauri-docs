[CrabNebula] 是 Tauri 的官方合作伙伴，为 Tauri 应用程序提供服务和工具。
[CrabNebula Cloud] 是一个应用程序分发平台，可与 Tauri 更新程序无缝集成。

Cloud 提供了一个内容分发网络 (CDN)，能够在全球范围内运送你的应用程序安装程序和更新，同时具有成本效益并公开下载指标。

使用 CrabNebula Cloud 服务，可以轻松实现多个发布渠道、应用程序网站的下载按钮等。

将你的 Tauri 应用程序设置为使用 Cloud 非常简单：你只需使用你的 GitHub 帐户登录 [Cloud 网站][Cloud website]，
创建你的组织和应用程序，并安装其 CLI 以创建发布并上传 Tauri 包。
此外，还提供了一个 [GitHub Action] 来简化在 GitHub 工作流中使用 CLI 的过程。

有关更多信息，请参阅 [CrabNebula Cloud 文档][CrabNebula Cloud documentation]。
