Tauri fournit les outils dont vous avez besoin pour distribuer votre application soit sur les magasins d'applications de la plateforme, soit sous forme d'installateurs spécifiques à la plateforme.

## Construction

Tauri construit votre application directement depuis sa CLI via les commandes `build`, `android build` et `ios build`.

<CommandTabs
  npm="npm run tauri build"
  yarn="yarn tauri build"
  pnpm="pnpm tauri build"
  deno="deno task tauri build"
  bun="bun tauri build"
  cargo="cargo tauri build"
/>

Consultez la section [distribution](#distribution) pour en savoir plus sur les options de configuration disponibles pour chaque bundle
et comment les distribuer à vos utilisateurs.

:::note
La plupart des plateformes nécessitent une signature de code. Consultez la section [signature](#signature) pour plus d'informations.
:::

### Empaquetage

Par défaut, la commande `build` empaquette automatiquement votre application pour les formats configurés.

Si vous avez besoin d'une personnalisation supplémentaire sur la façon dont les bundles de la plateforme sont générés, vous pouvez diviser les étapes de construction et d'empaquetage :

<CommandTabs
  npm="npm run tauri build -- --no-bundle
# empaqueter pour une distribution en dehors du macOS App Store
npm run tauri bundle -- --bundles app,dmg
# empaqueter pour une distribution sur l'App Store
npm run tauri bundle -- --bundles app --config src-tauri/tauri.appstore.conf.json"
  yarn="yarn tauri build --no-bundle
# empaqueter pour une distribution en dehors du macOS App Store
yarn tauri bundle --bundles app,dmg
# empaqueter pour une distribution sur l'App Store
yarn tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
  pnpm="pnpm tauri build --no-bundle
# empaqueter pour une distribution en dehors du macOS App Store
pnpm tauri bundle --bundles app,dmg
# empaqueter pour une distribution sur l'App Store
pnpm tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
  deno="deno task tauri build --no-bundle
# empaqueter pour une distribution en dehors du macOS App Store
deno task tauri bundle --bundles app,dmg
# empaqueter pour une distribution sur l'App Store
deno task tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
  bun="bun tauri build --no-bundle
# empaqueter pour une distribution en dehors du macOS App Store
bun tauri bundle --bundles app,dmg
# empaqueter pour une distribution sur l'App Store
bun tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
  cargo="cargo tauri build --no-bundle
# empaqueter pour une distribution en dehors du macOS App Store
cargo tauri bundle --bundles app,dmg
# empaqueter pour une distribution sur l'App Store
cargo tauri bundle --bundles app --config src-tauri/tauri.appstore.conf.json"
/>

## Gestion des versions

La version de votre application peut être définie dans l'option de configuration [`tauri.conf.json > version`],
ce qui est la méthode recommandée pour gérer la version de l'application. Si cette valeur de configuration n'est pas définie,
Tauri utilise la valeur `package > version` de votre fichier `src-tauri/Cargo.toml` à la place.

:::note
Certaines plateformes ont des limitations et des cas particuliers pour la chaîne de version.
Consultez les pages de documentation de distribution individuelles pour plus d'informations.
:::

## Signature

La signature de code améliore la sécurité de votre application en appliquant une signature numérique aux
exécutables et bundles de votre application, validant votre identité en tant que fournisseur de votre application.

La signature est requise sur la plupart des plateformes. Consultez la documentation de chaque plateforme pour plus d'informations.
