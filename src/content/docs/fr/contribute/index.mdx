Nous, les mainteneurs, sommes vraiment ravis que vous soyez intéressé à contribuer à Tauri. Nous accueillons les contributeurs de tout niveau de compétence et sommes heureux de fournir des conseils sur les PR.
En cas de doute, vous pouvez nous contacter sur [notre serveur Discord](https://discord.gg/SpmNs4S).

### Dépôts du projet

Les principaux dépôts Tauri auxquels vous pouvez contribuer sont :

- Le dépôt [Tauri Core](https://github.com/tauri-apps/tauri/) contenant le runtime Tauri, les outils de build, les macros et les utilitaires.
- Le dépôt [Plugins workspace](https://github.com/tauri-apps/plugins-workspace) avec tous les plugins officiels Tauri.
- Le dépôt [Tauri Docs](https://github.com/tauri-apps/tauri-docs) contenant ce site web.

Chacun de ces dépôts Tauri contient un fichier `.github/CONTRIBUTING.md`. Vous y trouverez des instructions sur la façon de configurer l'environnement de développement local et de soumettre une Pull Request.
