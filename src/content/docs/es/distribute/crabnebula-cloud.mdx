[CrabNebula] es un socio oficial de Tauri que brinda servicios y herramientas para aplicaciones Tauri.
[CrabNebula Cloud] es una plataforma para la distribución de aplicaciones que se integra perfectamente con el actualizador de Tauri.

Cloud ofrece una red de entrega de contenido (CDN) que es capaz de enviar los instaladores y actualizaciones de tu aplicación a nivel mundial, siendo rentable y exponiendo métricas de descarga.

Con el servicio CrabNebula Cloud es sencillo implementar múltiples canales de lanzamiento, botones de descarga para el sitio web de tu aplicación y más.

Configurar tu aplicación Tauri para usar Cloud es fácil: todo lo que necesitas hacer es iniciar sesión en el [sitio web de Cloud][Cloud website] usando tu cuenta de GitHub,
crear tu organización y aplicación e instalar su CLI para crear un lanzamiento y cargar los paquetes de Tauri.
Además, se proporciona una [GitHub Action] para simplificar el proceso de uso de la CLI en los flujos de trabajo de GitHub.

Para obtener más información, consulta la [documentación de CrabNebula Cloud][CrabNebula Cloud documentation].
